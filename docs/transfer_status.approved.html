Rules

  • Placement. Inside the film card, right column, where the old badge row and the hairline piece-bar slot were: between the description and the action row. Phones (<640px): the block spans the whole card under the poster row — the column is ~215px and the chain does not fit.
  • One component. Chain → piece bar → hint or plan box. The sticky bar mirrors exactly this block on scroll; no compact variant. No torrent name in the status or the sticky bar.
  • Direction. Left to right, towards the viewer. Never ↑ for “to you”: on a torrent site ↑ next to “you” reads as “you are seeding”, and ↑ is already the Vault cloud icon.
  • Units. Mbit/s everywhere (plans, speedtest and limit copy already use it). “≈ MB/s” only in the details popover.
  • Colour means cause. Cyan — data flowing; pink — the plan cap (the only place a CTA appears); amber — the swarm or a pause; purple — Vault; red — no seeders.
  • Motion. One sweep per segment: a single line under the speed label, a 30%-wide gradient moving background-position −43% → 143% in 1.8s, linear. The label and the arrowhead only brighten slightly (filter: brightness(1.18)) at 50% and ~90% of the cycle — no glow. prefers-reduced-motion: no sweep, the line is simply filled.
  • Stable DOM. Update text and classes in place on each SSE message; re-creating nodes restarts every animation once a second and drops clicks on the CTA.
  • Honest CTA. Plan box = bolt + title + ETA on the left, button with the trial note under it on the right (the download_file.html pattern). Download: “до N раз быстрее” while caching, “в N раз быстрее” for cached/Vault. Stream: only while the player is actually buffering; smooth playback shows the fact without a CTA. No CTA on pause, no/few seeders, stall, Vault failure. Anonymous viewers: “Без подписки — до 5 Мбит/с”, never “your plan”.
  • Zero vs unknown. Nothing flowing (including “not started yet”) — dimmed “Вы” and “—”. No data from the proxy — “Вы” is not drawn at all.
