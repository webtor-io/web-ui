# Перевод субтитров на язык зрителя (фаза 2 авто-субтитров)

Дата: 2026-09-13
Статус: дизайн на ревью владельца
Родительская спека: `docs/superpowers/specs/2026-09-12-auto-subtitles-design.md` (фаза 2)
Репозитории: новый сервис `subtitle-translate`; `web-ui` (лестница, модалка, гейт, телеметрия);
`infra/helmfile` (чарт, values, `torrent-http-proxy/services.yaml`). torrent-http-proxy не меняется.

## Проблема

После фазы 1 у большинства запусков есть дорожка-источник, но она чаще всего английская, а 63%
зрителей смотрят не на английском (pt 20%, es 11%, fr 8%, ru 6%, zh 5% сессий). Перевод
существующих дорожек закрывает эту разницу без CPU и без whisper: у фильма на 2 часа около 1 500
реплик, перевод батчами занимает 20–60 секунд и стоит порядка $0,3–0,5 на Haiku (счёт идёт по выходным
токенам: латиница дешевле, кириллица и индийские письменности дороже; оценка финального ревью 13.09).

## Решения владельца (2026-09-13)

1. Только платным тирам, пока без лимита. Бесплатным замок и CTA. Единый дневной AI-лимит на
   пользователя, из которого черпаются и подсказки, и переводы, появится позже отдельным слоем.
2. Целевой язык один: предпочитаемый язык зрителя. Это `stremio_settings.preferred_language`,
   если задан (явная настройка «язык релизов» в профиле, сейчас фильтрует стримы Stremio и
   Discover и снимается в подписки), иначе предпочитаемый язык; для анонимов только язык
   интерфейса. Отдельного выбора языка перевода в модалке нет; AI-дорожка подкидывается на
   предпочитаемом языке, и этого достаточно.
3. Перевод предлагается как дорожка на предпочитаемом языке с пометкой «AI», когда человеческой
   дорожки на этом языке нет. Дорожки OpenSubtitles и загруженные пользователем показываются в
   той же модалке с пометками происхождения.
4. Выдача прогрессивная, батчами.
5. Модель конфигурируется флагом, старт с Haiku 4.5.
6. Весь интерфейс внутри существующей модалки субтитров, без отдельных элементов на плеере.
7. Гейт на уровне web-ui. В THP ничего не зашиваем.
8. Дорожки OpenSubtitles переводить можно (проверка условий 2026-09-13: текстового запрета нет);
   в подписи переведённой дорожки сохраняется источник, переведённый VTT отдаётся только в
   плеер, без отдельной раздачи файлом.
9. Субтитры по умолчанию нужны только когда язык аудиодорожки не совпадает с предпочитаемым
   языком зрителя. При совпадении полные субтитры не включаются и перевод не запускается;
   всё остаётся доступным в модалке.
10. Исключение из п. 9: если аудио на предпочитаемом языке, но есть forced-дорожка (только
    надписи и иноязычные реплики) на предпочитаемом языке, она включается по умолчанию.
11. Переводы хранятся в S3 бессрочно, как и файлы OpenSubtitles сейчас.
12. Предпочитаемый язык вычисляется одной функцией `PreferredContentLang(user, ctx)` в web-ui;
    её же позже используют выбор аудиодорожки по умолчанию и Stremio-аддон (фаза 5).
13. Для NSFW-контента (`resource_metadata.is_adult`) AI-дорожка не предлагается и перевод не
    запускается: ни пункта «<язык> · AI», ни замка с CTA для бесплатных. Гейт в web-ui, там же,
    где тир: `Translate=false` при `is_adult`. Классификация — существующая (`docs/adult_classification.md`),
    неизвестный ресурс (нет строки метаданных) считается не-adult. Та же норма для whisper в фазе 3
    (2026-09-14).

## Что видит зритель

Модалка `#subtitles` получает в секции субтитров (`#embedded`) два изменения:

- **Пометка происхождения** у каждой дорожки: «Мои», «встроенные», «в раздаче», «OS», «AI».
  Дорожка, выбранная по умолчанию, подчёркнута как сейчас.
- **Дорожка «<Предпочитаемый язык> · AI»** появляется в списке, когда на предпочитаемом языке нет
  человеческой дорожки (уровни 0–4) и есть хотя бы одна текстовая дорожка-источник. Для
  платного это обычный пункт: клик запускает перевод, реплики появляются по мере готовности,
  рядом с пунктом идёт прогресс «12%». Она же становится дорожкой по умолчанию, но перевод
  стартует не на загрузке страницы, а при активации плеером после 5 секунд просмотра, чтобы не
  платить за тех, кто ушёл. Для бесплатного пункт с замком: клик открывает CTA на /donate с
  событием `donate-subtitle-translate`.
Ручного выбора языка перевода нет: AI-дорожка всегда на предпочитаемом языке. Зритель, который
хочет другой язык, меняет «предпочитаемый язык» в профиле или язык интерфейса.

**Правило «нужны ли субтитры вообще».** Язык активной аудиодорожки (по умолчанию первая
аудиодорожка пробы, `Tags.Language`; при переключении аудио в модалке правило пересчитывается)
сравнивается с предпочитаемым языком по базовому языку (`pt-BR` = `pt`).
- Совпадает → полные субтитры не включаются и AI-перевод не запускается. Если есть
  forced-дорожка на предпочитаемом языке (встроенная с признаком forced или приложенный файл с
  `forced` в имени), она включается по умолчанию с пометкой «надписи». Иначе дорожка по
  умолчанию «Нет». Список остаётся доступным.
- Не совпадает или язык аудио неизвестен → работает лестница ниже.
Переключение аудио в модалке пересчитывает правило: на предпочитаемый язык → выключить полные
субтитры и включить forced, если есть; на чужой язык → включить лучшую дорожку по лестнице.
Ручной выбор зрителя правило не трогает до конца просмотра.

Forced-дорожки в фазе 1 скрыты из списка по слову «forced» в названии. В фазе 2 они
возвращаются в список с пометкой «надписи», когда их язык совпадает с предпочитаемым языком, и
никогда не берутся как источник для перевода и как полные субтитры по лестнице. Признак forced
из `disposition` ffprobe появится, когда content-prober начнёт его отдавать (отдельная задача);
до этого эвристика по названию и имени файла.

Дорожка по умолчанию для предпочитаемого языка выбирается по лестнице, а не по порядку списка:
загруженные пользователем → встроенные → приложенные → OpenSubtitles (по хэшу, затем по imdb)
→ AI-перевод. Предпочитаемый язык берётся через `PreferredContentLang` (настройка профиля, иначе `c.Lang`), а не из Accept-Language.

## Архитектура

### Цепочка URL

`~tr:<lang>` применяется к любой субтитровой ссылке, которую уже умеет строить web-ui:

```
/<hash>/<path>/movie.srt~vtt/movie.vtt~tr:pt/movie.vtt            приложенный srt
/<hash>/<path>/movie.mkv~vi/opensubtitles/<id>.vtt~tr:pt/<id>.vtt   дорожка OpenSubtitles
/ext/<b64>/user.srt~vtt/user.vtt~tr:pt/user.vtt                      загруженная пользователем
```

THP разбирает только правый мод и отдаёт сервису `X-Source-Url`, указывающий обратно на THP с
внутренней цепочкой (`…/movie.srt~vtt/movie.vtt?token=…`); внутренний `~vtt` THP разрешает сам
при выборке источника. Внутренние переходы идут без `X-Forwarded-For` и не считаются
сессионным лимитером. `Mod.Extra` (`pt`) THP в заголовки не кладёт; сервис берёт язык из
собственного пути запроса, как это делает external-proxy. Встроенные дорожки (HLS-группа
транскодера) в фазе 2 не переводятся: у них нет самостоятельного URL; это отложено в фазу 3.

### Сервис `subtitle-translate`

Go, urfave/cli, шаблон srt2vtt. Зависимости: `common-services` (probes, Redis, S3),
`anthropic-sdk-go`, `go-astisub`. Флаги: `--model` (`SUBTITLE_TRANSLATE_MODEL`, по умолчанию
`claude-haiku-4-5-20251001`), `--anthropic-api-key`, `--batch-size` (50), `--max-cues` (5000),
`--max-source-bytes` (1 МиБ), `--prompt-version`, `--use-s3`, стандартные Redis/S3 флаги.

Один HTTP-маршрут: `GET|HEAD /<anything>~tr:<lang>/<name>.vtt`. `HEAD` отдаёт только
заголовки (в том числе `X-Subtitle-Progress`) и не запускает задачу; плеер опрашивает
прогресс им.

1. Разбор: язык из пути (2-буквенный код из списка языков `services/stremio/helper.go`,
   он шире 11 языков интерфейса; иначе 400), источник из
   `X-Source-Url`, глоссарий из query `names=` (до 30 имён через запятую, опционально).
2. Ключ артефакта `k = sha256(X-Info-Hash + X-Path + lang + model + promptVersion)`: `X-Path`
   для цепочки сохраняет внутренние моды (`/movie.srt~vtt/movie.vtt`,
   `/movie.mkv~vi/opensubtitles/123.vtt`), так что ключ однозначно называет источник и не
   зависит от токена в `X-Source-Url`. Попадание в кэш не требует выборки источника. Исходник
   выбирается через THP по `X-Source-Url` только при запуске задачи, с таймаутом 30 с; больше
   `--max-source-bytes` или `--max-cues` → 413 с текстом. Один и тот же файл в разных
   раздачах переводится дважды; дедупликация по содержимому отложена.
3. Если в S3 есть `k` → 200, полный VTT, `X-Subtitle-Progress: 100`. Иначе первый запрос
   запускает фоновую задачу (singleflight в поде по `k` плюс замок в Redis `tr:lock:k` на 10
   минут) и отвечает 200 с тем, что уже есть в Redis (`tr:cues:k`, список переведённых батчей),
   минимум заголовок `WEBVTT`, и `X-Subtitle-Progress: <готово>/<всего>`. Повторные запросы
   отдают текущее состояние. Рестарт пода: следующий запрос видит замок истёкшим и продолжает
   с первого непереведённого батча.
4. Пайплайн задачи: нормализация (вырезать HI-теги `[…]`, `(…)`, `♪`-строки без текста,
   склеить реплики, разорванные на две cue переносом), нарезка по `--batch-size` реплик,
   запрос модели на батч с контекстом (последние 5 реплик предыдущего батча, глоссарий, язык
   источника если известен, целевой язык), температура 0, ответ строго построчно с
   сохранением id; несовпадение числа строк → повтор батча один раз, затем батч помечается
   ошибочным и оригинальные реплики отдаются без перевода с пометкой в логе. Тайминги и
   позиционирование cue не меняются. Каждый готовый батч пишется в Redis; по завершении полный
   VTT в S3 (свой бакет `subtitle-translate`, ключ `<k>.vtt`; один бакет на сервис) и
   Redis-ключи чистятся.
5. Ошибки: нет ключа API → 501 с текстом «translation is not configured»; источник недоступен →
   404 с причиной; ошибка модели после ретраев → 502 с причиной; `Retry-After` не нужен,
   плеер сам перечитывает по прогрессу.
6. Ответные заголовки: `Content-Type: text/vtt; charset=utf-8`, `X-Subtitle-Progress`,
   `Cache-Control: no-store` пока перевод не завершён, `public, max-age=86400` после.
7. Метрики Prometheus: батчи, токены ввода/вывода, длительность задачи, ошибки по типу.
   Логи structured, без текста реплик.

Промпт держится в одном файле с версией; смена версии меняет ключ артефакта. Провайдер
модели за интерфейсом `Translator` с одной реализацией; имя провайдера в публичном коде только
в конфигурационных флагах и README, в ошибках «upstream».

### web-ui

- **Правило по языку аудио** в `GetSubtitles`: элемент `Translated` добавляется и полная
  дорожка по умолчанию назначается только если базовый язык первой аудиодорожки пробы
  отличается от предпочитаемого языка или неизвестен; при совпадении дорожкой по умолчанию
  становится forced-дорожка на предпочитаемом языке, если есть. `ListItem` получает `Forced bool`;
  `embeddedSubtitleVisible` перестаёт скрывать forced-дорожки на предпочитаемом языке. Плеер
  получает `data-audio-lang` на элементах аудио и `data-forced` на дорожках и пересчитывает
  выбор при переключении аудио (JS-хелпер с тестами: `pickDefaultSubtitle(tracks, audioLang,
  preferredLang)`).
- **Лестница для предпочитаемого языка** в `GetSubtitles`: сначала человеческая дорожка на
  предпочитаемом языке по лестнице 0–4, она становится дорожкой по умолчанию; иначе выбирается
  источник для перевода (язык оригинальной аудиодорожки, затем английский, затем первая
  текстовая) и добавляется элемент провайдера `Translated` с `Src = <src источника>~tr:<lang>/
  <name>.vtt&names=<глоссарий>`, `SrcLang = lang`, `Label = "<Язык> · AI (из <источник>)"`,
  `Default = true`, `Preload = false`. Для бесплатного тот же элемент без `Src` и с `Locked`.
- **Глоссарий**: имена из TMDB-каста enrichment (до 30), добавляются в query `names=`.
- **Гейт**: `Locked` вычисляется из `claims.IsPaid`; `~tr` URL никогда не рендерится
  бесплатному. THP не проверяет мод, поэтому платный может передать ссылку; ссылка живёт
  столько же, сколько его токен, и привязана к хэшу. Принято как известный риск, при
  злоупотреблении переходим к клейму тира в токене THP (отдельная задача).
- **Плеер**: элемент `Translated` активируется как любой side-loaded (`ensureTrackElement`);
  после `load` дорожки плеер читает `X-Subtitle-Progress` из ответа. Так как `<track>` не даёт
  доступа к заголовкам, прогресс запрашивается отдельным `fetch(src, {method:'HEAD'})` раз в 3
  секунды до 100%, а `<track>` перезагружается сменой `src` на тот же URL с `&rev=<n>` при
  каждом изменении прогресса. Активные cues при перезагрузке сохраняются механизмом
  `captureTrackState`/`restoreTrackState`. Cue-offset для сессий с середины уже работает
  для side-loaded дорожек.
- **Модалка**: пометки происхождения по `data-provider`/`data-source`, пункт «AI», замок и
  CTA для бесплатных, прогресс рядом с активной AI-дорожкой, пометка «надписи» у forced.
- **Эндпоинт старта не нужен в фазе 2**: перевод запускается самим GET дорожки. Единый
  дневной AI-лимит позже встанет в `GetSubtitles` (не отдавать `Src` при исчерпании) и в
  сервис не попадёт.
- **Embed-виджет** (`embed-sdk-js`) не получает `Translated` в фазе 2.

### THP

Одна запись `tr: {name: subtitle-translate}` в `values/torrent-http-proxy/services.yaml`
(дефолтная `Hash`-дистрибуция, без `preferLocalNode`). Расширение `.vtt` уже в `lightExts`, и
после `limiterPath` (bda31c2) запрос `~tr/…vtt` учитывается под своим путём.

### Гейтинг по возможностям

Мод показывается только когда сервис объявлен в `services.yaml` и у web-ui включён флаг
`--subtitle-translate-enabled`; отсутствие ключа API у сервиса даёт 501 с объяснением, а не
пустую дорожку. Флаг web-ui по умолчанию выключен, в self-hosted README перечислен как
неподдерживаемый без ключа.

## Телеметрия

- `subtitle-resolved` получает `translated` (bool: дорожка по умолчанию это AI), `badge`
  (`user|embedded|sidecar|os|ai|none`), `audioLang` и `needed` (bool: язык аудио отличается от
  предпочитаемого языка). Гистограмма уровней читается только по `needed=true`.
- `subtitle-translate-start` `{lang, source, cues}`, `subtitle-translate-done` `{lang,
  seconds, cues}`, `subtitle-translate-error` `{lang, code}`, `subtitle-translate-lock-click`
  `{lang}`. `badge` получает значение `forced`.
- `report-problem` в модалке получает вариант «плохой перевод» с `data-provider=Translated`.

## Пороги успеха (8 недель после релиза)

- Доля запусков с дорожкой на языке зрителя (человеческой или AI) растёт с ~20% до 40%.
- Конверсия в триал у видевших замок не ниже средней /donate (~8%).
- Ошибки перевода (`subtitle-translate-error`) меньше 2% стартов.
- Стоимость: считается из метрик токенов, ориентир $0,15 на фильм, сверяется с биллингом.

## Риски

- **Качество на длинных фильмах**: имена и обращения дрейфуют между батчами; глоссарий и
  контекст из предыдущего батча это смягчают, полностью не убирают.
- **Несовпадение числа строк в ответе модели**: ретрай батча, затем оригинал без перевода;
  метрика по этому случаю обязательна.
- **Стоимость без квоты**: только платные и кэш по источнику; при аномалии (один пользователь
  запускает десятки переводов в час) включается единый AI-лимит раньше плана.
- **Передача ссылки**: описано в гейте.
- **Источник плохого качества**: перевод HI-версии без вырезания тегов или машинного
  перевода OpenSubtitles (они уже отфильтрованы в фазе 1).

## Тестирование

- Сервис: юнит на нормализацию VTT (HI-теги, склейка), нарезку батчей и сборку обратно с
  сохранением id и таймингов, парсинг языка из пути, ключ артефакта; тест с фейковым
  `Translator` на прогрессивную выдачу (первый ответ пустой с прогрессом, следующий с батчем,
  финальный из S3), на ретрай при несовпадении строк, на 501 без ключа, на 413 по лимитам.
  Интеграционный прогон на одном настоящем VTT с реальной моделью только вручную перед
  релизом, с проверкой стоимости по метрикам.
- web-ui: `GetSubtitles` на правило по языку аудио (совпадает → нет AI-элемента, по умолчанию
  forced на предпочитаемом языке или ничего; отличается или неизвестен → лестница), на лестницу для
  предпочитаемого языка (человеческая дорожка побеждает AI; forced никогда не источник и не полная
  дорожка; источник выбирается по языку аудио, затем en), на `Locked` для бесплатных, на
  сборку `~tr` URL; JS-тесты на `pickDefaultSubtitle`, полл прогресса и обновление `src`;
  `make test`, `npm test`.
